## Reporting a Vulnerability

We take the security of **Hi5** seriously. If you discover a security vulnerability, please follow these steps:

1. **Do not create a public GitHub issue.**
2. Send an email to the repository maintainer or open a private GitHub Security Advisory under the repository's **Security** tab.
3. Include detailed steps to reproduce the issue:
   - A description of the vulnerability.
   - Proof-of-concept steps or exploit code (if available).
   - The impact of the vulnerability.

We will acknowledge receipt of your vulnerability report within 48 hours and provide a timeline for addressing the issue.

Thank you for helping keep Hi5 safe and secure for everyone!
